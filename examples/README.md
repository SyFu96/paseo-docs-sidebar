# Docs sidebar demo workspace

Open this folder as a Paseo workspace, then open the **Docs** tab in the explorer.

- `demo.md`: Markdown with math, a table, inline and reference images, and links to the HTML and Word samples.
- `demo.html`: self-contained HTML preview with inline styles and a local data image.
- `demo.docx`: Word reading view with headings, a table, and an embedded image.
- `very-long-file-name-for-testing-the-resizable-file-tree-in-the-docs-sidebar.md`: long name for testing the resizable file tree.
- `assets/demo.png`: shared demo image.
